Built for Real-World Speed & Simplicity

📶

NFC HCE Bump

Emulates an NFC Forum Type 4 Tag (v1.0 & v2.0) so touching an iPhone triggers iOS Background Tag Reading instantly.

📄

600 MB+ Safe Streaming

Large docs & videos stream directly to Safari’s Download Manager via HTTP 206 Range with live /progress updates—zero WebKit RAM crash.

📥

Two-Way MediaStore Drop Box

iPad & iPhone upload straight through Safari into Android Pictures, Movies, and Downloads/PixelBump after you tap Accept.

⚡

Offline Wi-Fi Lock Tuning

Acquires WIFI_MODE_FULL_LOW_LATENCY, PARTIAL_WAKE_LOCK, and 256 KB TCP buffers so offline transfers avoid 802.11 power-save throttling.

📡

Guided Hotspot QR

Supports Same Wi-Fi (1-scan) and Pixel Hotspot (2-step Wi-Fi Join + Safari Link) with smart ap*/wlan* subnet detection.

🔒

Hardened Local Bridge

16-char per-file session tokens, same-origin enforcement, allowBackup="false", and network_security_config.xml outbound cleartext block.
